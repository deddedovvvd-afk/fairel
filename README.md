# Poultry Strike

Оригинальная мини-игра для Android: аркадная стрельба от первого лица по забавным куриным ботам на тренировочной арене. Это самостоятельная игра, не использующая ресурсы Chicken Gun или Standoff.

## Управление
- Левая нижняя зона: движение/смещение прицела.
- Правая нижняя красная кнопка или касание экрана: выстрел.
- «Перезарядка»: восстановить 12 патронов.
- Попадание приносит очко.

Сборка debug APK выполняется GitHub Actions.
